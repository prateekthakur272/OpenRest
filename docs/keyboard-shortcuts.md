# Keyboard shortcuts

On Windows and Linux use **Ctrl** where this page says **⌘**. The same list is in **Preferences ▸ Shortcuts** and the menus show each shortcut next to its item.

## General

| Shortcut | Action |
|---|---|
| ⌘K or ⌘P | Command palette |
| ⌘, | Preferences |
| ⌘B | Show or hide the sidebar |
| ⌘⇧L | Switch between stacked and side-by-side layout |
| ⌘+ / ⌘− / ⌘0 | Zoom in / out / reset |
| Esc | Close a dialog or menu |

## Requests

| Shortcut | Action |
|---|---|
| ⌘↵ | Send the request |
| ⌘S | Save |
| ⌘⇧S | Save all |
| ⌘N | New request (or new collection when none is open) |
| ⌘L | Focus the URL bar |
| ⌘⇧C | Copy the request as cURL |

## Tabs

| Shortcut | Action |
|---|---|
| ⌘W | Close the tab |
| ⌘1 … ⌘9 | Go to tab 1 to 8; ⌘9 goes to the last tab |
| Ctrl+Tab / Ctrl+⇧Tab | Next / previous tab |
| ⌘⇧] / ⌘⇧[ | Next / previous tab |

## Sidebar

| Key | Action |
|---|---|
| ↑ ↓ ← → | Move through the tree and open or close folders |
| ↵ | Open the selected request |
| F2 | Rename |
| Delete | Delete |

## macOS and Windows specifics

- macOS: About, Preferences and Quit are in the application menu (⌘Q quits).
- Windows and Linux: Preferences and Exit are in the **File** menu; Ctrl+Q quits.
